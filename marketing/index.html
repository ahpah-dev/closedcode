Is ClosedCode really free and unlimited?

ClosedCode has no app subscription, license key, or app usage cap. AI models are separate: providers can have quotas or usage charges, and local inference uses your hardware. Free models only blocks paid and unverified routes.

Can I sell or relicense my own version?

Yes. Original ClosedCode code is dedicated to the public domain through the Unlicense. You can copy, modify, redistribute, relicense, and monetize it without asking permission or giving credit. Third-party dependencies retain their own licenses.

Which models can I connect?

Connect an OpenAI-compatible endpoint, use OmniRoute as a gateway, or discover installed local Ollama models. With Free models only enabled, ClosedCode checks the catalog for verified zero-cost, compatible models before inference. Availability depends on your provider and account.

What stays on my computer?

Your local companion works in the project folder you choose. Model requests send the relevant context to your configured provider. A local model route uses the service running on your own computer. Choose your provider and workspace deliberately.

How do agents and subagents work?

Atlas builds, Nova explores, Sage reviews, and Echo debugs. Each has a focused approach. The subagents plugin allows up to two focused, read-only investigations by another agent. Plugins add file context, Git diff review, and local or HTTP MCP tools. External tool calls require approval in Build mode.

Why is a download unavailable for my platform?

Each download appears when its actual app package is published in a GitHub release. macOS downloads can be DMG installers or ZIP archives. The platform chooser reports that availability. If a build is not published yet, the public source remains available for building locally.
